
# SecureFile Vault

A Python-based cybersecurity project for secure, password-protected file encryption and decryption.

## Project Goals

- Encrypt and decrypt local files securely.
- Use established cryptographic algorithms and libraries.
- Protect file confidentiality and integrity.
- Handle incorrect passwords and corrupted files safely.
- Provide a simple command-line interface.
- Include automated tests and documentation.

## Technology Stack

- Python 3.13
- cryptography
- pytest
- Git and GitHub

## Status

Under active development.
